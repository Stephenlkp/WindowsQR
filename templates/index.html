Send a file

Receive a file from {{ host_label }}

  1. In the QR AirDrop desktop window, choose Choose Files for Phone and select the files to offer.
  2. On your phone, open /api/phone-files from this app's URL (iPhone Shortcuts can scan the QR and append that path).
  3. Choose a file, download it, then save it where you want.

Keep QR AirDrop running until the download finishes.

Set up an iPhone Shortcut

After scanning the QR code, append api/phone-files (or the older api/iphone-files) to the scanned URL. Use Get Contents of URL (GET), get the files dictionary value, choose a file, get its download_url, fetch that URL with GET, then pass the downloaded result to Save File.

Phone won't paste your image or file?

Some apps do not share copied files with the browser. On iPhone, use an Apple Shortcut: Get Clipboard → Scan QR or Barcode → Text: scanned URL followed by clipboard/files → Get Contents of URL (POST, Form, key file, type File, value Clipboard).

The QR address already ends with a slash. Use the Clipboard variable as the file value, not the QR result. You can also send a shared file using Shortcut Input as the value. On Android, use Send a file above if paste is blocked.
