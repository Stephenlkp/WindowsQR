Receive a file from Windows

  1. In the WindowsQR desktop window, choose Choose Files for iPhone and select the PC files to offer.
  2. On your iPhone, run the Windows to iPhone Transfer Shortcut and scan this app's QR code.
  3. Choose Get a file, select a file, then use Save File and confirm where to save it.

Keep WindowsQR running until the download finishes. In the iPhone Files app, check the folder you chose; Recents is only a view of recent items, not the save location.

Set up the file transfer Shortcut

After scanning the QR code, append api/iphone-files to the scanned URL. Use Get Contents of URL (GET), get the files dictionary value, choose a file, get its download_url, fetch that URL with GET, then pass the downloaded result to Save File.

Send images or files (iOS Clipboard) to Windows Clipboard

Copy an image or file on your iPhone, then touch and hold the box below and choose Paste.

No image or file pasted.

After sending, press Ctrl+V in a Windows app for an image, or in File Explorer for files.

iOS won't paste your image or file?

Some iOS apps do not share copied files with Safari. Use an Apple Shortcut: Get Clipboard → Scan QR or Barcode → Text: scanned URL followed by clipboard/files → Get Contents of URL (POST, Form, key file, type File, value Clipboard).

The QR address already ends with a slash. Use the Clipboard variable as the file value, not the QR result. You can also send a shared file using Shortcut Input as the value.
